### IHaveAlreadySeenIt

一个免费、开源、仅在本机运行的 macOS 微信防撤回补丁管理器。项目使用 SwiftUI 构建图形界面，同时提供可审计 CLI、严格版本白名单、完整备份与事务回滚机制，重点关注本地隐私、安全边界和可恢复性。

`Swift` `SwiftUI` `macOS` `CLI` `Security` `GPL-3.0`
